# CONTENT MIGRATION

## Rules

- Spanish is the default language.
- English is supplied for shared interface text and verified route summaries; a missing translation is labelled rather than invented.
- WordPress query-string duplicates map to one clean canonical route.
- Administrative, author, comments, feed, JSON API and XML-RPC artifacts are excluded from public navigation.
- Contact, payment and application actions are not simulated.

## Known gaps

- The downloaded mirror contains public images and PDFs without explicit licence metadata. They are marked as requiring permission or replacement before public redistribution.
- Some source pages are historical, duplicated or contain third-party embeds. Their migration status is recorded in `docs/PAGE_INVENTORY.md`.
- English content coverage is partial until an authorised bilingual source is provided.
